If you actually use AI chat tools day to day, you know the annoying part,
different models are better at different things, so you end up with four
tabs open, copy-pasting the same question between them to compare answers.
And when you actually need to save or share a good conversation, most apps
give you an ugly text dump, not something you'd hand to someone else.

Orion puts that in one place. Switch between models inside the same
conversation thread, and when a chat is worth keeping, export it as a
clean, properly formatted PDF instead of a wall of copy-pasted text.

---

## What it does

- **Switch between AI models** without losing the thread of the
  conversation.
- **Export chats as clean PDFs**, dark-themed and properly formatted, not a
  raw text dump.
- **A dark UI actually designed for it**, tuned for OLED screens instead of
  just inverting a light theme.
- **Markdown rendering**, so code blocks and formatting show up the way
  they're meant to.
- **Full chat history**, saved locally, so you can go back to old
  conversations any time.
